# 東京首都圈隨機地圖選取器

一個互動式的網頁應用程式，用於隨機選取東京首都圈（東京都及其相鄰縣市）的市區鎮。

## 功能特色

### 🗺️ 地理範圍
- **東京都**：23區、26市、5町、8村
- **神奈川縣**：19市、13町、1村
- **埼玉縣**：40市、22町、2村
- **千葉縣**：37市、6町、1村
- **山梨縣**：13市、8町、6村

### ✨ 主要功能
1. **互動式地圖**：使用 Leaflet.js 顯示東京首都圈地圖
2. **隨機選取**：根據用戶輸入數量隨機選取區域
3. **視覺標示**：選取到的區域會在地圖上高亮顯示
4. **詳細信息**：顯示區域的縣市、類型、人口、面積等信息
5. **響應式設計**：支援桌面和移動設備

### 🎯 使用方式

#### 基本操作
1. **輸入數量**：在「選取數量」輸入框中輸入想要選取的區域數量（1-50）
2. **隨機選取**：點擊「隨機選取」按鈕進行隨機選取
3. **清除選取**：點擊「清除選取」按鈕清除所有選取
4. **手動選取**：直接點擊地圖上的區域進行手動選取

#### 快捷鍵
- `Ctrl/Cmd + R`：隨機選取
- `Ctrl/Cmd + C`：清除選取

#### 地圖操作
- **縮放**：使用滑鼠滾輪或地圖控制按鈕
- **拖拽**：按住滑鼠左鍵拖拽地圖
- **懸停**：滑鼠懸停在區域上查看詳細信息

### 數據格式
使用 GeoJSON 格式存儲地理數據，包含以下信息：
- 區域名稱
- 所屬縣市
- 行政區劃類型（區、市、町、村）
- 人口數量
- 面積（平方公里）
- 地理坐標

## 安裝和運行

### 本地運行
1. 克隆或下載項目文件
2. 使用本地伺服器運行（推薦）：
   ```bash
   # 使用 Python
   python -m http.server 8000
   
   # 使用 Node.js
   npx http-server
   
   # 使用 PHP
   php -S localhost:8000
   ```
3. 在瀏覽器中訪問 `http://localhost:8000`

### 直接運行
由於使用了外部地圖服務，建議使用本地伺服器運行以避免 CORS 問題。

## 開發說明

### 添加新區域
在 `js/data.js` 文件中添加新的 GeoJSON 特徵：

```javascript
{
    "type": "Feature",
    "properties": {
        "name": "區域名稱",
        "prefecture": "縣市名稱",
        "type": "區/市/町/村",
        "population": 人口數量,
        "area_km2": 面積
    },
    "geometry": {
        "type": "Polygon",
        "coordinates": [[[經度, 緯度], ...]]
    }
}
```

### 自定義樣式
在 `css/style.css` 中修改樣式，或在 `js/map.js` 中修改地圖樣式函數。
